# customer-behavior-analysis
1️.Data Loading

Imported the dataset using Python (Pandas).
Performed initial inspection (shape, data types, missing values).

2️.Exploratory Data Analysis (EDA)

Analyzed customer demographics and purchase patterns.
Identified trends in:
Spending behavior
Discount usage
Shipping preferences
Subscription status

3️.Data Cleaning

Handled missing values.
Corrected data types.
Removed duplicates and inconsistent records.

4️.SQL Analysis

Imported cleaned data into PostgreSQL/MySQL.
Executed SQL queries to calculate:
Total revenue
Average purchase amount
Discount usage rate
Subscription-based spending
Used GROUP BY, JOIN, ORDER BY, and aggregate functions.

5️.Power BI Dashboard

Built an interactive dashboard featuring:
Revenue by category
Customer segmentation
Discount impact analysis
Shipping and payment trends

6️.Reporting & Presentation:

Created a detailed analytical report.
Designed a professional PPT using Gamma for stakeholder presentation.

**Dashboard Highlights:

Revenue trends by customer segment
Impact of discounts on purchase behavior
Subscription vs non-subscription customer analysis
Shipping and payment method preferences
